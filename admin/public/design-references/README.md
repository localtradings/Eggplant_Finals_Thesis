# Planta Admin visual references

These references were generated as one consistent forest-green botanical direction for the admin workspace. The page references cover Overview, Global scans, Reports, Disease requests, Disease catalog, Settings, and Admin access. The smaller illustrations cover empty states, catalog publishing/deletion, security, synchronization, artwork presentation, login, and audit history.

The live interface uses the direction selectively: the botanical texture is a low-contrast page backdrop, the login hero is used on the sign-in screen, and catalog artwork uses whole-image frames. Operational data remains rendered as real text, controls, and tables so none of the existing admin actions are hidden behind artwork.

The current v2 set in `v2/` contains ten page-level references used for the redesign: Overview, Global scans, Reports, Disease requests, Disease catalog, Settings, Admin access, the responsive shell, empty states, and login. They are references for spacing, hierarchy, color, imagery, and composition; the app implements those decisions with real HTML, controls, and server-rendered data.
